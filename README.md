# Natzirt-BK

Open-source tools and practical Linux support for tuning Subaru vehicles,
including ECU diagnostics, ROM editing, and datalogging workflows.

## Current project

- [Subaru ECU Tools for Linux](https://github.com/Natzirt-BK/subaru-ecu-tools-linux) — an experimental OpenPort 2.0 Wine bridge for EcuFlash, plus portable RomRaider editor and logger launch helpers.

The project focuses on reproducible setup instructions, hardware-access fixes,
and cautious read-only validation before any ECU writing is attempted.
